UPDATES / HOW CURRENT IT IS

How current it is.

Release 3 is built on Chromium 157.0.8103.38. Chrome 157 came out about 3 November 2026.

The short answer

Each release moves to a newer Chromium, through ungoogled-chromium. It arrives days to weeks after the same version of Chrome, and sometimes skips versions. Chrome now ships a new version about every two weeks. One person cannot keep up with that.

If you need every Chrome security fix the day it ships, use a browser with a full-time team behind it, such as Firefox, Brave or Chrome.

Each release

  • Release 3 · November 2026 · Chromium 157.0.8103.38. About a week after Chrome 157. Chrome 155 and 156 came out between release 2 and release 3. This browser stayed on 154 for about six weeks and skipped them.
  • Release 2 · 29 September 2026 · Chromium 154.0.8037.57. About a week after Chrome 154, which came out about 22 September 2026.
  • Release 1 · 25 September 2026 · Chromium 153.0.8010.52. Chrome 153 came out about 8 September 2026 and Chrome 154 about 22 September, so it was one version behind on the day.

Google also ships smaller updates inside each version. Those after 157.0.8103.38 are not in Release 3. They come with the next release.

Why it takes time

First ungoogled-chromium releases its version for Windows. Then our own patches, about 80 of them, are moved onto it, built and tested. Moving from 154 to 157 took about two days of work, then hours of building and a full test run.

How fixes reach you

  • An installed copy asks our site once a day whether a new release is out.
  • A new release installs only after you agree, and only if it carries our signature.
  • The zip does not update. Install a new release yourself.
  • If you turn the daily check off, check for updates yourself on the Protection page.
  • Blocking lists are separate. The browser checks for new ones about once a week and uses them only if they carry our signature. New lists are published by hand for now. The last was on 14 October 2026.

How often

There is no fixed schedule. A release ships when the move to a newer Chromium is built and tested. Some privacy reviewers ask for engine updates within a day of Chrome. We do not meet that.
