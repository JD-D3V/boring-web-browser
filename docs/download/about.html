ABOUT THE PROJECT / WHO AND WHY

Who makes this, and why.

Written for Release 3, November 2026. Boring Browser 3 on Chromium 157.0.8103.38, Windows x64.

Who

One person: JD-D3V on GitHub, a solo developer. There is no company, team or investor behind it. Every release is built on JD-D3V's own PC and published from that GitHub account. The source code and every release are public.

Why this matters: a browser updates itself, so whoever makes it can put new code on your computer. That is why an update installs only after you agree, and only if it carries our signature. You can turn the daily check off on the Protection page.

Why it exists

A browser should be boring. It should open the page and stay out of the way. Many browsers now come with ads, sponsored tiles, shopping features, crypto wallets or AI you did not ask for. This one is meant to be private from the start and to make scam sites harder to fall for, for you and for the people you help with their computers.

How it is paid for

It is not. There is no income: no ads, no search deal, no donations, no paid version and no data to sell. JD-D3V builds it unpaid. The cost of that is speed. See how current it is.

Why Chromium

  • Sites are built and tested for Chromium's engine, so they work.
  • Google's security team keeps fixing that engine. Those fixes reach this browser each time it moves to a newer Chromium.
  • Extensions from the Chrome Web Store work.

The cost: the engine is Google's, and we follow its pace. If you want a browser that does not use Google's engine at all, Firefox and Mullvad Browser are good choices.

Why ungoogled-chromium

ungoogled-chromium is an open source project that takes Chromium and removes Google's services and its background connections to Google. We start from it. On top sit about 80 small patches of our own: blocking, the Protection page, the scam warnings and the look.

In our measurements on Release 3, the browser on its own reached only Quad9's secure DNS, and GitHub when it checked for blocking lists. With everything that contacts a server turned off, it contacted nothing. The Chromium Web Store helper talks to Google, but only if you have Chrome Web Store extensions. The privacy page lists every connection.

What it will never do

  • Show you ads or sponsored tiles.
  • Sell or share your data. It sends us no usage data, so there is nothing to sell. The update check sends only the browser version.
  • Ask you to make an account.
  • Add crypto, wallets or coins.
  • Turn on AI for you. Page summaries stay off until you pick a provider, and run only when you click.
  • Install an update without asking you first.
  • Weaken Chromium's sandbox, the wall that keeps a bad page away from the rest of your computer.

Who checks the work

Nobody outside, yet. Release 3 had five security reviews of our own and a full automated test run. That is not an outside audit. The source is public, so anyone can check it. See the security fixes in each release and the threat model.
