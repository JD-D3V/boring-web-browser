Privacy & preview notices.

Pre-release information · 19 September 2026. No approved binary is offered yet. Final browser network behavior, support contacts and release-specific notices must be verified before downloads open.

This download website

This static website contains no analytics, advertising, remote fonts or cookies. Its problem report form prepares an email locally without submitting or storing it on a server. If you send it, JD and the email service receive your address and included content to investigate and respond. Contact jmill004@mtroyal.ca for support, private security concerns or report-deletion requests; provider retention and backup rules may apply. Do not send sensitive records or credentials.

Following an external link sends a request to that service. If hosted on GitHub Pages, GitHub processes hosting requests, including technical information such as IP addresses, under its privacy statement. No claim of anonymous access is made.

The browser and your data

Browsing sends requests to the sites you visit. Searches go to your selected search provider; provider policies apply. Browser profiles can hold history, cookies, saved credentials, settings and downloads. Use a separate profile for preview testing. Uninstalling an application does not necessarily remove its profile or downloaded files.

Optional remote AI summaries can send page content to the provider you choose. Do not use them on confidential, school or personal records without permission. Local and remote processing must not be treated as interchangeable.

Ad-filter rules are evaluated in the browser. Filter-list refreshes, where configured, contact a release host; that host receives the request's network information. The release must state whether authenticated list updates are operational or rules are a fixed snapshot. No automatic browser updater is included in v1. A final first-run and background-network audit is still required; this page does not promise that the browser makes no background requests.

Protection has limits

URLhaus and OpenPhish scam/malware lists are excluded from v1. Ad/tracker blocking and popup protection are not antivirus and cannot establish that a site or download is safe. Blocking can miss unwanted content or interfere with legitimate sites. Keep Windows security protections enabled.

Preview use and support

This is experimental software, not a promise of fitness for important work, uninterrupted service, complete protection or compatibility. Back up important data and keep a maintained browser available. No support or update response time is guaranteed. These notices do not remove rights you have under applicable law.

Before a binary release, JD must publish the supported Windows versions, known issues, verified installation/removal steps, update instructions and support/private security-reporting route. Do not share browsing profiles, passwords, access tokens or student records in public reports. The preview is not represented as a school-approved or managed deployment.

The final package must include the upstream licence, Chromium third-party notices and supplemental Rust dependency notices. Download integrity and signing

Final release notes will identify exact files, SHA-256 hashes and actual signature status. A checksum detects changed bytes; it is not an independent guarantee of safety. An unsigned build may be blocked or show warnings. Even valid code signing does not guarantee an absence of SmartScreen warnings. See Microsoft's explanation. Do not disable security software to try the preview.

Release withdrawal

If a preview is withdrawn for a security or reliability issue, stop using it and return to a maintained browser until an approved replacement is available. The release page will need to identify withdrawn versions explicitly; old downloads must not remain presented as recommended.
