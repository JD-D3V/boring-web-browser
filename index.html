READ BEFORE INSTALLING / KEEP FOR REFERENCE

The small print.
In a readable size.

Not your daily browser yet

Use a separate test profile. Keep a maintained browser for sensitive accounts and important work. On school-managed devices, ask your IT administrator before installing.

No scam-site database in v1

URLhaus and OpenPhish data are excluded from v1. Ad blocking and popup protection do not replace malware or phishing protection.

Updates need your attention

Without automatic browser updates, you must check for new releases and update manually. Stop using a withdrawn or outdated preview. No maintenance timetable is promised yet.

Windows warnings matter

An unsigned or unfamiliar build may trigger a warning. Don’t disable Defender or SmartScreen. Signing, when available, identifies a publisher; it does not guarantee safety.

How will I check a download?

Use only the official release linked here once available. Compare its exact filename and SHA-256 with the published checksum file. In PowerShell:

Get-FileHash -Algorithm SHA256 -LiteralPath 'C:\Downloads\EXACT-FILENAME.exe'

A matching hash confirms matching bytes, not that the software is harmless or the download site uncompromised. Read the release’s signing status and known issues before running it.

Will streaming and every website work?

Compatibility is still being tested. Widevine is not bundled, so DRM-dependent services may not work. Blocking can also break individual sites. Final release notes will list tested behavior and unresolved issues.

Where do I report a problem?

Report a problem to JD by email, including security or privacy concerns. Never send passwords, API keys, school records or browser profiles. This independent project does not offer guaranteed support.
