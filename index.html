WHAT YOU'LL SEE / WHEN YOU OPEN THE INSTALLER

Windows will stop you once.

The installer is not signed yet; signing is planned once the project has more users. Until then Windows cannot tell who made the file, so it shows a blue warning. That is expected for this release. First check the hash, then open the installer.

Drawings, not screenshots. Your screen may look a little different. If the name is different, or Windows says the file is dangerous rather than unrecognized, stop and tell JD. Never turn off Defender or SmartScreen to get past this.

READ BEFORE INSTALLING / KEEP FOR REFERENCE

The small print.
In a readable size.

On from the start

Ad, tracker and pop-up blocking, the way uBlock Origin does it. HTTPS first. Quad9 secure DNS. Fingerprint noise on canvas, text and element sizes. Tracking parameters removed from links to other sites. WebRTC kept to proxied routes. DuckDuckGo search by default. Pick Google, Bing, Brave or Ecosia from the search icon.

Dangerous sites, by name

Quad9 refuses known malware and phishing sites, so they do not open. There is no warning page, and new or unreported sites get through. It does not replace Windows security.

Extensions

Chrome Web Store extensions install, and every install asks first. The store helper is built in and can be removed. It changes only with a browser update.

Your things, your call

Import bookmarks, history and search engines from Chrome or Edge. Never passwords or cookies. Spellcheck works without a download. Turn off blocking on one site from the toolbar shield.

Senior Safe Mode

One switch for a parent or grandparent. Sponsored search results stay hidden, and the browser asks before the mode can be turned off.

Updates

Checks our site once a day. A new release installs only after you agree, and only with our signature. Installed copies only; the zip does not update. Turn the check off on the Protection page.

Windows will warn

This build is not signed, so SmartScreen will warn. Don’t turn off Defender or SmartScreen. Check the hash instead.

Not in release 2

Scam warning page and scam list. Widevine, so no DRM video. Sync. Tor windows. Code signing.

How do I check a download?

Do this before you select Run anyway. Use only the official release linked here. Compare its exact filename and SHA-256 with the published checksum file. In PowerShell:

Get-FileHash -Algorithm SHA256 -LiteralPath 'C:\Downloads\EXACT-FILENAME.exe'

For release 2 the installer's SHA-256 is F25A0BE546DBAF6D573BAD978976B54406C06E872551B95146304CE21552B0C8. The number PowerShell prints has to be the same, every character.

A matching hash confirms matching bytes, not that the software is harmless or the download site uncompromised. Read the release notes before running it.

Will streaming and every website work?

Netflix and other DRM video will not play. Widevine is not in release 2. Blocking and fingerprint noise can break parts of some sites. Fingerprint noise has a switch on the Protection page. See the known issues.

Where do I report a problem?

Report a problem to JD by email, including security or privacy concerns. Never send passwords, API keys, school records or browser profiles. This independent project does not offer guaranteed support.
